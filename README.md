# Video Banner

**Автор проекта: Кушалиев Амир** · [Telegram: @foidslayer1038](https://t.me/foidslayer1038)

Приложение для Windows для подготовки видео и наложения баннерной рекламы.

**Стек:** C# · Windows Forms · FFmpeg · yt-dlp.

## Сборка и запуск

1. Нужна Windows с .NET Framework и компилятором C#.
2. Откройте `Собрать.cmd` — появится `ВидеоБаннер.exe`.
3. Откройте `Установить-компоненты.cmd` для установки FFmpeg, FFprobe, yt-dlp и Node.js. Нужен интернет; установщик проверяет контрольные суммы.
4. Откройте `Запустить.cmd` или собранное приложение.
5. Выберите исходное видео, настройте баннер и параметры экспорта в интерфейсе.

В репозитории опубликованы исходники и установщик компонентов. Сторонние программы, исходные видео, рекламные материалы и результаты экспорта устанавливаются или добавляются отдельно. FFmpeg и yt-dlp сохраняют собственные лицензии.
